# Projectile Motion Practice

A self-contained, single-file practice site for high school algebra-based physics: concept review, a vector-addition sandbox, a shuffled multiple-choice quiz, randomized problem-solving practice, and an interactive launch simulator.

No build step, no dependencies to install — it's one HTML file with inline CSS and JavaScript.

## Put it online with GitHub Pages (free)

1. Create a new repository on GitHub (public repos get free Pages hosting).
2. Upload `index.html` to the root of that repository (drag-and-drop on the GitHub website works, or `git add`/`commit`/`push` from the command line).
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **Deploy from a branch**.
5. Under **Branch**, choose `main` (or `master`) and folder `/ (root)`, then **Save**.
6. Wait a minute or two, then refresh that Pages settings screen — it will show your live URL, something like:
   `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`

That link is what you can share with students, post in your LMS, or bookmark.

## Making changes later

Just edit `index.html` (it's plain HTML/CSS/JavaScript — search for the section you want, e.g. `MULTIPLE CHOICE QUIZ` or `LAUNCH SIMULATOR`) and push the updated file to the same repository. GitHub Pages redeploys automatically within a minute or two of a push to the branch you selected.
